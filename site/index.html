Plugins

Panels, layouts and site tweaks people made for Valerie. Find one here, then install it from Plugins in Valerie's command bar.

Made one? Share it.

When your AI makes you a plugin, Valerie offers to share it. You can also run Share Plugin in the command bar, or valerie plugins share <name>.

Valerie opens a pull request from your GitHub account. Once it's reviewed and merged, it shows up here and in everyone's Plugins window.

Read the rules for plugins

Every file is pinned to the commit it was reviewed at and checksummed, so what you install is what was reviewed.
